# RICH300 행동형 포지션 후속 알림 (2026-11-11)

## Scope
- 적용 대상: 텔레그램 [진입했어]를 눌러 opt-in 하고 [정리했어]로 종료하지 않은 RICH300 후속 추적.
- 기존 COIN RADAR 추천/스캔, 기존 2버튼, 기존 시트/Fill/Equity, 기존 운영 배포/트리거, Binance 주문 기능은 **변경하지 않음**.
- 사용되는 가격·봉: OKX/Bybit **공개 읽기 전용** 시세. Binance 체결/잔량을 의미하지 않음.

## 2시간 정기 보고 내용
1. 현 시세, 추천 진입 대비 방향 변화(%), 최초 손절폭 기준의 **가격 R**(실제 투자 수익률 아님).
2. 최초 손절선까지 현 가격 거리(%, R), TP1/TP2까지 거리 또는 **현재가 기준 도달** 표시.
3. 1H·4H EMA 추세, 1H 거래량, 15분 **마감봉** 4봉 범위 이탈 여부와 거래량.
4. 평가 등급(추세 유지/약화/역행, 15분 반대돌파, 손절 임박/이탈, 목표 도달), 각 상황에서의 **조건부** 유지·축소·청산·익절 검토, 다음 확정봉 점검 수준.
5. 원래 추천 근거, 거래소 실제 체결 미확인, 수수료·증거금·레버리지·수익 비확정 고지.
6. **확정봉 기반 지지·저항**: 최근 1H 36봉·4H 18봉에서 좌우 마감 봉으로 확정된 피벗 및 최근 1H 24봉/4H 12봉의 고저를 사용. 현재가 아래 지지·위 저항 각각 최대 두 가격과 근거를 명시. 일치하는 구간이 없으면 근거 부족으로 표시(돌파 이후 미확인 목표 추정 금지).
7. **최초 TP1·TP2와 조정 검토 가격**: 최초 목표는 수정 없이 항상 보여 준다. 유리한 방향에 있는 실제 확정 지지·저항 앞 0.1%를 **조건부 신규 목표 후보**로 계산하며, 1R 미만 보상 또는 현재가와 0.25% 미만이면 변경 보류 표시. 최초 TP를 넘었으면 실제 체결 확인을 먼저 안내하고, 기존 목표보다 연장된 경우에는 1H 확정봉 돌파 확인이 선행 조건이다.
8. **손절 후보**: 기존 추천 손절선을 언제나 함께 표시. 1R 이상 유리하게 진행했으며 확정 방어 구간이 있고 새 후보가 기존 손절선보다 최소 0.25R 유리하면서 현재가와 최소 0.3% 떨어져 있을 때만 방어적인 당기기 검토 가격을 제시한다. 손절 확대/자동 주문 변경 없음.
9. **유지/축소 분기**: 가까운 지지 이탈·저항 돌파를 1H 종가 기준으로 명시하고 다음 대응을 설명한다. 수준·현재가·봉 정보가 신뢰되지 않으면 수치 대신 분석 유보.

## 시간 사이 변경 경고
- 기존 5분 `rich300WatchTick` 트리거를 사용하되 **최대 15분에 1번** 시세를 조회(새 트리거 생성 안 함).
- 긴급 경고: 최초 손절선 이탈/0.25R 이내, 최초 TP1/TP2 현재가 도달, 1H·4H 방향 동시 역행, 거래량 1.2배 이상 동반 15분 반대돌파(상위 봉 일부 역행 시).
- 15분 판단에는 **확정 봉만** 사용하고 최근 봉이 없으면 돌파 판단을 하지 않음.
- 직전 긴급 상태와 같으면 재발송하지 않음; 다른 긴급 상태도 기본 30분 쿨다운(손절 이탈은 우선 경고). 기본 2시간 정기 보고 주기는 별도 유지.
- 시세가 오래되었거나 API 데이터가 이상하면 기존 가드에 따라 **보고·경고 모두 차단**.
- 알림 보내기 전에 상태를 저장해 이중 전송을 피함(실패/타임아웃 시 긴급 알림은 중복 전송보다 at-most-once 우선).

## 운영 검증
- RICH300 CI: 번들 생성·GAS 문법 검사, lib+Telegram/ops 테스트, 모바일 브라우저 회귀검사.
- 운영 배포는 GitHub PR/병합과 별개. 기존 Apps Script의 소스 백업, 운영/리포지토리 parity 확인, 동일 Deployment ID 버전 갱신, 실 데이터 무변경, 실제 Telegram 수신 검증을 반드시 진행.
- 종료 버튼 후 재활성화 금지, 마감/체결/수익 자동 기록 금지, 자동 매매 금지.
- 15분 간격은 감시 실행의 최대 빈도이며 네트워크·락·GAS 실행/트리거 제약에 따라 지연될 수 있음; 실시간 가격·실시간 손절 집행 대체물이 아님.

## 동적 가격 분석 제약
- 가격은 OKX/Bybit 공개 시장 데이터(1H·4H **확정** 캔들)에서 계산한 **관찰 구간**이지 매수·매도 체결 가능 가격이나 미래 예측을 보장하지 않는다. 표시상의 목표는 자동으로 사용자의 Binance/OKX 계정 주문에 반영되지 않는다.
- 소형 코인 가격은 최대 소수 10자리로 표시한다. 수수료·펀딩·슬리피지로 실제 유효 손익비가 달라지므로 조정은 반드시 사용자가 거래소 주문 및 체결 상황을 확인한 뒤 결정해야 한다.
- **긴급 경고는 지금과 동일한 15분 단위 상태 변화 알림**을 유지하며 2시간 보고와 독립 실행된다.


## 정기 보고 유지·정리 근거 강화
- 확정 1H/4H 종가·EMA20·EMA50 수치, 최근 15분 4봉씩의 저점(LONG)/고점(SHORT) 비교, 가까운 방어선과 현재가 거리 및 1H 종가 이탈 조건을 제시한다.
- 정기 보고 시에만 BTC 공개 시세를 실행당 한 번 추가 조회해 1H/4H 방향을 비교한다. BTC 데이터가 누락·지연·역행하면 단순 추세 유지 상태를 그대로 유지 결론으로 표시하지 않는다. 데이터 부족 시 판단 보류, 목표 도달 시 실제 체결 확인, 위험 상태 시 축소·정리 조건 검토로 표시한다.
- 기존 2시간 주기, 15분 긴급 감시 및 최초 손절/목표 계산과 주문 미연동 원칙은 변경하지 않는다. 운영 반영 전 Apps Script 번들 재생성, 자동 테스트 및 기존 프로젝트 배포·실제 알림 검증이 필요하다.
