# RICH300 행동형 포지션 후속 알림 (2026-11-11)

## Scope
- 적용 대상: 텔레그램 [진입했어]를 눌러 opt-in 하고 [정리했어]로 종료하지 않은 RICH300 후속 추적.
- 기존 COIN RADAR 추천/스캔, 기존 2버튼, 기존 시트/Fill/Equity, 기존 운영 배포/트리거, Binance 주문 기능은 **변경하지 않음**.
- 사용되는 가격·봉: OKX/Bybit **공개 읽기 전용** 시세. Binance 체결/잔량을 의미하지 않음.

## 1시간 보고 내용
1. 현 시세, 추천 진입 대비 방향 변화(%), 최초 손절폭 기준의 **가격 R**(실제 투자 수익률 아님).
2. 최초 손절선까지 현 가격 거리(%, R), TP1/TP2까지 거리 또는 **현재가 기준 도달** 표시.
3. 1H·4H EMA 추세, 1H 거래량, 15분 **마감봉** 4봉 범위 이탈 여부와 거래량.
4. 평가 등급(추세 유지/약화/역행, 15분 반대돌파, 손절 임박/이탈, 목표 도달), 각 상황에서의 **조건부** 유지·축소·청산·익절 검토, 다음 확정봉 점검 수준.
5. 원래 추천 근거, 거래소 실제 체결 미확인, 수수료·증거금·레버리지·수익 비확정 고지.

## 시간 사이 변경 경고
- 기존 5분 `rich300WatchTick` 트리거를 사용하되 **최대 15분에 1번** 시세를 조회(새 트리거 생성 안 함).
- 긴급 경고: 최초 손절선 이탈/0.25R 이내, 최초 TP1/TP2 현재가 도달, 1H·4H 방향 동시 역행, 거래량 1.2배 이상 동반 15분 반대돌파(상위 봉 일부 역행 시).
- 15분 판단에는 **확정 봉만** 사용하고 최근 봉이 없으면 돌파 판단을 하지 않음.
- 직전 긴급 상태와 같으면 재발송하지 않음; 다른 긴급 상태도 기본 30분 쿨다운(손절 이탈은 우선 경고). 기본 1시간 보고 주기는 별도 유지.
- 시세가 오래되었거나 API 데이터가 이상하면 기존 가드에 따라 **보고·경고 모두 차단**.
- 알림 보내기 전에 상태를 저장해 이중 전송을 피함(실패/타임아웃 시 긴급 알림은 중복 전송보다 at-most-once 우선).

## 운영 검증
- RICH300 CI: 번들 생성·GAS 문법 검사, lib+Telegram/ops 테스트, 모바일 브라우저 회귀검사.
- 운영 배포는 GitHub PR/병합과 별개. 기존 Apps Script의 소스 백업, 운영/리포지토리 parity 확인, 동일 Deployment ID 버전 갱신, 실 데이터 무변경, 실제 Telegram 수신 검증을 반드시 진행.
- 종료 버튼 후 재활성화 금지, 마감/체결/수익 자동 기록 금지, 자동 매매 금지.
- 15분 간격은 감시 실행의 최대 빈도이며 네트워크·락·GAS 실행/트리거 제약에 따라 지연될 수 있음; 실시간 가격·실시간 손절 집행 대체물이 아님.
