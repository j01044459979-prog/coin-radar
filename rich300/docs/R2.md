# RICH 300 — R2 계산 엔진

순수 함수 라이브러리(`rich300/lib/`). 저장소·네트워크·Telegram·시간대 설정에 의존하지 않고, 같은 입력이면 항상 같은 결과를 낸다.

| 모듈 | 내용 |
|---|---|
| `decimal.mjs` | BigInt 고정소수점(10⁻¹²). 십진 문자열 정확 파싱(12자리 초과는 오류), 반올림은 0에서 먼 쪽, 금액은 마이크로 USDT(10⁻⁶) 정수 |
| `time.mjs` | KST 거래일(00:00 경계) 순수 산술: `kstDayOf`, `dayStartMs`, `addDays`, `dayRange` |
| `compound.mjs` | 당일 목표 = 전일 **실제** 마감 × (1+목표율), 이상 복리선 = 시작 × Π(1+g)(분수 연산, 목표율 변경은 변경일부터) |
| `pnl.mjs` | LONG/SHORT 실현손익, 추가 진입·부분/전량 청산(평균 원가 가중평균), 수수료·펀딩 3상태(입력/추정/미입력), **모의(origin≠real) 거부** |
| `ledger.mjs` | 일별 목표·실제·이상선, 입출금 분리, 장부 대 입력 평가액 차이(허용치 max(1 USDT, 0.5%)), 시작 시 미결제 포지션 기준가 재설정, 누적 수익률·최고 평가액·최대 낙폭 |
| `risk.mjs` | 거래당 위험%, 증거금·레버리지 일치, 청산가 **근사**, 경고 플래그(차단 아님) |
| `dedupe.mjs` | 같은 id·같은 내용=무시, 다른 내용=충돌, 비슷한 체결 후보 표시, 추가 전용 리비전·void |
| `build.mjs` | GAS 단일 파일 번들(`node rich300/build.mjs`, 산출물은 저장소에 커밋하지 않음) |

## 규칙(코드로 고정)
- **미달분 보정 없음**: 어제 목표를 못 채워도 오늘 목표는 어제 실제 마감 × 1.05 뿐이다.
- **입출금 분리**: 일 손익 = 마감 − 시작 − 순입출금. 목표 기준(전일 마감)에 입출금이 섞이지 않는다. 최대 낙폭은 입출금을 뺀 곡선으로 계산한다.
- **추정 금지**: 미입력 수수료·펀딩은 합계에서 빼고 경고, 추정치는 별도 합계(`netWithEstimates`). 평가액 미입력일은 장부 근사(`closeSource=ledger`)로 **표시**한다.
- **차이는 숨기지 않는다**: 입력 평가액과 장부 잔고의 차이를 항상 계산하고, 허용치를 넘으면 `needsReview`. 자동으로 손익에 흡수하지 않으며 사용자가 이유와 함께 넣은 `adjustment`만 반영한다.
- **금액 표현**: 마이크로 USDT BigInt. Sheets 저장은 `microToNumber`(안전 정수 범위만).
- **정합성 한계**: 청산가는 근사, 최대 낙폭은 일 마감 평가액 기준(일중 낙폭 아님), 시작 시 미결제 포지션의 `origEntry`가 없으면 `opening-basis-unknown`으로 불확실 표시.
