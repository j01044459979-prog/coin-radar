# RICH 300 — S0 실측 계획 (Apps Script 가정 검증)

> 목적: 설계의 미검증 가정 5개를 **실측**으로 확정한다. S0에는 비밀·Telegram·실제 거래 데이터가 없다(시험용 프로젝트, 끝나면 삭제).
> 이 개발 환경은 `script.google.com`·`api.telegram.org`에 접근할 수 없다(실측: 연결 실패). 그래서 측정 클라이언트는 **GitHub Actions**에서 실행하고, 로그에는 URL·본문 없이 집계 결과만 남긴다.

## 측정 항목과 판정 규칙
| # | 가정 | 측정 방법 | 판정 → 설계 결정 |
|---|---|---|---|
| ① | `doPost`는 헤더를 못 읽는다 | Actions가 `x-s0-probe`·`authorization` 헤더를 붙여 POST, 이벤트 객체 키·응답에서 노출 여부 확인 | 노출 없음 → **본문 HMAC 서명**(설계 §5) 확정. 노출되면 헤더 서명도 허용 |
| ② | POST 응답이 302 | `redirect: manual`로 1차 상태·Location 확인, 따라간 최종 본문 확인 | 302 → **Telegram 웹훅 모드 기각**(Telegram은 non-2xx를 실패로 보고 재전송) → **getUpdates 폴링 확정**. 200 → 웹훅 허용(재전송은 update_id로 방어) |
| ②' | 302를 따라가도 POST 실행은 1회 | POST 3회 전후 서버 카운터 비교 | 3 → 정상. 그 외 → 중복 실행 위험, 설계 수정 |
| ③ | UI 배포(방문자로 실행)에서 방문자 이메일 확인 가능 | 사용자가 UI URL을 열어 JSON의 `activeUserEmail`·`effectiveUserEmail` 확인 | 이메일 보임 → **이메일 허용 목록** 확정. 비어 있으면 `effectiveUserEmail`로 대체 가능 여부 확인, 둘 다 비면 "시트 접근권한(소유자만)에 의존 + 별도 PIN" 대안 |
| ④ | 한 프로젝트에 설정이 다른 웹앱 배포 2개 | 사용자가 배포 2개를 만들 수 있는지(실행 주체·접근 범위 설정) | 가능 → 설계대로. 불가 → API·UI를 **두 프로젝트**로 분리 |
| ⑤a | 쓰기·락 | 병렬 POST 8건: 카운터 고유값 수·합, `appendRow` 지연 | 8건 모두 고유·순서대로 → 락으로 직렬화 정상 |
| ⑤b | 트리거 | 1분 트리거 실행시간·간격, 매일 0시 트리거의 **실제 실행 시각**(0~1시 창) | 실행시간 평균 <2초이면 폴링 1분 가능. 0시 트리거 지연을 마감 로직 가정에 반영 |
| ⑤c | 쿼터 | API 없음 → **Google 공식 문서로 재확인**(트리거 90분/일, UrlFetch 2만/일, 실행 6분 등) | 사용량 추정치와 비교해 한도 여유 확인 |
| 인증 | 익명 `doGet` | API 배포에 GET 요청 | 응답이 비어 있어야 함(데이터 노출 없음) |

## 필요한 Google 작업 (최소화)
1. **프로브 프로젝트 1개**: Drive 커넥터로 빈 Apps Script 프로젝트를 만들어 `rich300/s0/Code.gs`를 넣는 것을 시도합니다(커넥터 한계로 안 되면 사용자가 `script.new`에 붙여넣기 1회).
2. **배포 2개**(웹앱, 사용자 클릭): 
   - API용: 실행 주체 *나* / 접근 *누구나* → URL을 GitHub Secret `RICH300_S0_API_URL`에 등록(또는 시험용이라 채팅으로 전달 후 삭제).
   - UI용: 실행 주체 *웹앱에 접속하는 사용자* / 접근 *Google 계정이 있는 모든 사용자* → 브라우저로 열어 JSON 한 줄을 알려 주기.
3. 편집기에서 `s0InstallTriggers` 1회 실행(권한 승인 포함) → 약 30분 후 `s0Report` 실행해 결과 한 줄 전달, 다음 날 0시 트리거 결과는 `s0Report`로 재확인.
4. S0 종료 후 `s0RemoveTriggers` 실행, 시험 시트·프로젝트·배포 삭제.
Actions 측정은 Secret이 등록되면 `rich300/s0/**`에 push(또는 수동 실행)할 때 자동 실행됩니다.
