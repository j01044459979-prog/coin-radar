## 단계별 완료 기준
- R2: 계산 라이브러리가 손계산 값과 일치(예: 300×1.05=315, 입출금 분리, 부분 청산 가중평균), 모든 금액 정수 마이크로 연산, GAS 빌드 문법 검사 통과.
- R3~R5: 중복·재전송·동시 쓰기에서 레코드 1건·감사 로그 정합.
- R4: 비페어링 발신자 무응답, 저장 버튼 전 기록 없음(복기 기본값 비저장).
- R7: 목표 달성 여부가 신호·알림 경로로 전달되지 않음(역방향 경로 없음 테스트).
- 배포(승인 후): 사본 백업 → 배포 → 허용/비허용 계정 시험 → 24시간 관찰.
