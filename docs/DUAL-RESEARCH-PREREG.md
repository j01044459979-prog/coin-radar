# 듀얼 전략 3.0 연구 사전 등록 (결과를 보기 전에 고정)

작성 시점: 이 문서는 3년치 데이터 연구 실행(`research-dual` 워크플로) **이전** 커밋으로 남긴다. 이 문서의 가설·기준·절차는 결과를 본 뒤 바꾸지 않는다. 바뀌면 변경 이유와 함께 별도 항목으로 기록한다.

## 데이터와 기간
- OKX 공개 1시간봉(`history-candles`), 고정 후보 37종목(`radar-service/backtest/CANDIDATES.json`) + BTC, 최대 1,095일(2023-10-17 ~ 2026-10-17).
- 이전 백테스트(PR #24, 2025-10-17 ~ 2026-10-17)는 **이미 결과를 본 구간**이라 최종 테스트로 쓰지 않고, 참고용 `seen` 구간으로만 보고한다.

| 구간 | 기간(UTC) | 용도 |
|---|---|---|
| 개발 `dev` | 2023-11-16 ~ 2024-10-17 | 진단·허용 국면(H3) 도출. 탐색 허용 |
| 검증 `val` | 2024-10-17 ~ 2025-04-17 | 가설 1차 판정. 규칙 변경 금지 |
| 최종 `final` | 2025-04-17 ~ 2025-10-17 | 규칙·코드 해시 고정 후 **1회만** 평가 |
| 이미 본 구간 `seen` | 2025-10-17 ~ | 참고(결과를 이미 본 데이터) |
- 시간 순서: dev → val → final → seen. 구간 경계의 purge(경계를 가로지르는 거래 제외)와 엠바고(dev 이후 구간은 시작 후 48시간 진입 제외) 적용.
- 유니버스: 구간 시작 **직전 30일** 거래대금 합 상위 20종목(그 시점에 상장된 종목만, BTC 항상 포함). 현재 거래되는 종목만 수집하므로 생존 편향은 남는다(완화일 뿐 제거 아님).

## 가설 (각각 원본 대비 변경점 1개)
- **H1**: 전략 B에서 재테스트 완료(`structureType == retest`)를 필수 조건으로 추가. 점수·손절·목표 불변.
- **H2**: 전략 A에서 Supertrend 전환 후 36봉(age > 35) 초과 진입 금지. 점수·손절·목표 불변. (12봉 변형은 탐색용 민감도, 가설 검정 아님)
- **H3**: 시장 국면별 실행 제한. 허용 국면 = 개발 구간에서 거래 ≥ 30이고 비용 반영 평균 R > 0인 국면(전략별). 없으면 전략 비활성. 같은 국면 제한을 건 무작위 진입을 기준선으로 함께 보고.
- 평가 방식: 거래 수 감소는 개선으로 보지 않는다. 원본 신호 중 **유지된 신호 vs 제거된 신호**의 평균 R 차이(주 블록 부트스트랩 95% 구간)와 무작위 기준선 대비 성과로 판단한다.

## 잠정 통과 기준 (연구 단계, 운영 적용 기준 아님)
1. 청산 거래 ≥ 100 2. 비용 반영 평균 R > 0 3. 평균 R의 95% 신뢰구간(진입 주 단위 블록 부트스트랩) 하한 > 0 4. Profit Factor ≥ 1.15 5. 국면(n≥20) 중 ≥ 2곳에서 양수 6. 상위 3종목 제외 후에도 양수 7. 비용 1.5배·2배 스트레스에서도 평균 R > 0 8. 기존 전략 대비 낙폭·거래 비용 악화 여부 보고.
- 통과해도 즉시 운영하지 않는다(그림자 모드 후보 판정까지만). 미달이면 실패로 보고하고 임계값·규칙을 바꾸지 않는다.

## 최종 테스트 절차
1. dev·val 결과 확인 후 규칙을 고정하고 `FROZEN_HASH`(규칙 파일 해시)와 이 문서를 커밋.
2. 그 커밋에서 새 브랜치 `research/dual-final`을 **한 번** 푸시 → `research-dual-final` 워크플로가 해시 일치를 확인하고 final 구간을 평가(해시 불일치 시 중단). 이후 그 브랜치에는 푸시하지 않는다.
3. 결과는 통과/실패와 무관하게 그대로 보고한다.
