# 백테스트 엔진 검증 및 수정 내역 (PR #24 엔진 대비)

검증 방법: 코드 정독 + 단위 테스트 + 3년치 실데이터 거래 불변식 점검(`engineAudit`). 결과 수치는 `docs/DUAL-RESEARCH-REPORT.md`의 1절(실행 로그 기반)에 있다.

## 확인한 항목과 결과
| 항목 | 방법 | 결과 |
|---|---|---|
| 미래 데이터 참조 | (1) 모든 지표가 인과적(i번째 값은 0..i 캔들만) (2) 테스트: 데이터를 i에서 잘라 계산한 값 = 전체로 계산한 값 (3) 테스트: 미래 봉을 바꿔도 과거 신호 불변 — 지표·전략 A·B·결합·원시 신호까지 | 문제 없음 |
| 캔들 정렬 | 모든 캔들 시각이 정시인지, OHLC 범위가 유효한지 로드 시 검사. BTC와는 타임스탬프로 매핑(인덱스 매핑 아님) | 위반 시 연구 중단 |
| 시간 간극 | 간극을 감지해 세그먼트 분할(워밍업 재시작), BTC에 간극이 있으면 중단 | **기존엔 점검이 없었음 → 추가** |
| 신호 확정 vs 체결 가능 시점 | 신호는 i봉 마감 후 계산, 체결은 i+1봉 시가. 불변식 점검: `tEntry == c[i+1].t` | 문제 없음 |
| 봉 내부 손절·익절 | 같은 봉에서 둘 다 닿으면 손절 우선(보수적). 순서 불명 거래 비율과 '목표 우선' 낙관 상한을 함께 보고 | **기존엔 영향 범위를 몰랐음 → 정량화 추가** |
| 갭 | 진입 시가가 손절·목표 바깥이면 거래 안 함, 보유 중 시가가 손절 밖이면 시가로 청산 | 테스트로 확인 |
| 수수료·슬리피지·펀딩 | 편도 0.05%+0.05%, 펀딩 0.01%/8h 고정 가정을 R로 환산. 불변식: 순손익 ≤ 총손익 | 문제 없음(가정은 단순화) |
| 최소 주문 단위·호가 단위 | OKX 계약 사양(`tickSz`, `lotSz`, `minSz`, `ctVal`)으로 체결가를 불리하게 반올림, 자본 $10,000·위험 1% 수량이 최소 수량 미달이면 거래 제외, 수량 반올림 위험 오차 보고 | **기존엔 미반영 → 추가** |
| 동시 포지션·포트폴리오 낙폭 | 종목 간 겹침 통계, 동시 5개 상한 포트폴리오(복리) 낙폭, 보유기간 겹침 제거 표본 | **기존 'MDD(R)'은 종목별 거래를 시간순으로 합산한 값이라 포트폴리오 낙폭이 아니었음 → 분리** |
| 신뢰구간 | 거래를 독립으로 본 부트스트랩 → 진입 주 단위 블록 부트스트랩 | **기존 구간이 과도하게 좁았음 → 교체** |
| 시간 순서 검증·purge/embargo | 구간 [from,to) 밖 신호 무시, 경계를 가로지르는 거래 제외(purge), 개발 이후 구간 시작 48시간 엠바고 | **추가** |
| 데이터 끝 미청산 거래 | 이전: 마지막 캔들 종가로 강제 시간 청산 → 변경: 집계 제외 | **수정(소폭)** |
| 유니버스 | 기존: 현재 거래대금 상위 고정 → 변경: 구간 시작 직전 30일 거래대금 상위(시점별), BTC 항상 포함 | 생존 편향은 일부만 완화 |
| 5분 운영 전략 vs 1시간 근사 | 기존(근사)은 가격·거래량 성분만 1시간봉에 옮긴 것(OI·펀딩 이력 없음). 운영 중인 5분봉 전략의 성과로 읽지 않는다 | 보고서 모든 표에 명시 |

## 수정 내역 (코드)
- `engine.mjs`: `simulateTrade`에 MFE/MAE(R), 순서 불명(`ambiguous`)과 낙관 상한(`rNetOpt`), 호가 단위·최소 수량(옵션), 데이터 끝 강제 청산 제거, `runSymbol`의 [from,to) 윈도우와 purge.
- `stats.mjs`(신규): 주 블록 부트스트랩, 쌍체 차이 구간, 보유기간 겹침 제거, 동시 보유, 포트폴리오 시뮬레이션, 그룹 분해 표.
- `research.mjs`(신규): 간극 분할·정렬 검사, 시점별 유니버스, 허용 국면 규칙, 변형 실행(점수 1회 계산 후 차단 사유만 추가 → 가설 간 차이가 변경점뿐임), 거래 불변식 점검.
- `strategyA/B.mjs`: 진단용 수치 특징(`features`)과 연구용 옵션(`maxAge`, `requireRetest`) 노출 — 점수 계산은 변경 없음(테스트로 확인).
- 이전 백테스트 수치(PR #24 문서)는 '비용 반영 후 음수, 유의한 양의 기대값 없음'이라는 결론은 유지되지만, 신뢰구간은 위 사유로 **과소평가되었을 가능성**이 있다.
