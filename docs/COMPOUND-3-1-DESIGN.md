## 1. 목표를 지표로 바꾸기
- "하루 1~2회"는 **목표 신호율이 아니라 모니터링 지표**다. 신호를 만들기 위해 임계값을 낮추지 않는다(규칙: 사전 등록 임계값 변경 금지, 변경은 새 버전 + 새 표본).
- 안전장치: 하루 상한(기본 A+B 합 4건), 같은 종목·방향 중복 금지, 최소 손익비·구조 손절 미충족 시 제외, 시장 데이터 공백이면 침묵.

## 3. 전략 명세
### A전략 · 추세돌파형
기존 SIGNAL 3.0 유지: 4H 추세 + 1H 눌림(2단계↑) + 15m 확정 돌파 + 거래량 ×1.2, 진입=트리거 봉 종가, 구조적 손절, 목표는 확정 구간, 비용 반영 손익비 ≥1.5R, 유효 45분, 쿨다운 2시간.

### B전략 · 눌림목 재진입형 (사전 등록 가설 — 값은 **검증 전 제안값**이며 결과를 보고 바꾸지 않는다)
모든 입력은 확정 봉. 미래 봉 참조 금지(백테스트는 봉 마감 시각 ≤ 판정 시각만).
1. **방향(1H)**: 마지막 확정 1H 종가 > EMA50 이고 EMA20 > EMA50 이고 EMA50 기울기(최근 6봉) > 0 → LONG. SHORT 대칭.
2. **재시험(15m)** — 최근 8개 확정 15분봉 안에서 다음 중 하나가 발생: (a) 저가(LONG; SHORT는 고가)가 15m EMA20의 ±0.25×ATR14(15m) 이내까지 접근·터치, (b) 1H 확정 스윙 지지(저항) 구간 [lo,hi] 안으로 진입(꼬리 포함, 종가는 구간 하단 −0.25×ATR14 아래로 마감하지 않음).
3. **반전봉(트리거)**: 재시험 이후 첫 확정 15분봉 중 (i) LONG: 양봉, 종가 > 직전 봉 고가 또는 종가가 봉 범위 상위 40% 이상이며 아랫꼬리 ≥ 몸통(핀바/장악형), (ii) 종가가 15m EMA20 위. SHORT 대칭. 트리거 봉 마감 후 20분 이내에만 유효.
4. **거래량**: 트리거 봉 거래대금 ≥ 직전 20봉 평균 × 0.8 (결측이면 제외).
5. **손절(구조)**: LONG = min(재시험 구간 저점, 구간 하단) − 0.25×ATR14(15m); 거리 1.0~3.5×ATR(1H) 밖이면 제외. 불명확하면 신호 제외.
6. **목표**: TP1 = 진입 + 1.5R, TP2 = 진입 + 2.0R (초기 검증 가설).
7. **필터**: 같은 종목·방향 활성 신호가 있으면 제외, BTC 4H 방향과 역방향이면 표시만(제외 아님, 검증에서 별도 코호트).

**명세 충돌(결정 필요)**: "비용 반영 손익비 ≥1.5R"와 "TP1=1.5R(총)"은 동시에 성립하지 않는다(비용 약 0.05~0.1R이 빠져 순 1.5R 미만 → 항상 제외). 선택지: (가) TP1 = 1.5R + 비용R(순 1.5R 보장, 권장) (나) 최소 기준을 **총** 1.5R로 두고 순R은 참고 표시. 승인 전까지 (가)로 구현·백테스트하되 두 변형을 모두 기록한다.

## 4. 위험 관리 (모의 계산 전용, 주문 없음)
- 1R = 계좌 위험 예산(기본 0.5%, 초기 검증 옵션 0.25%). 수량 = 모의 계좌 × 위험% ÷ 손절 거리. 수치는 표시와 기록용이며 실제 계좌와 연결하지 않는다.
- 필요 레버리지 = 명목 ÷ 모의 계좌. 청산 근사: 격리 마진 기준 청산 거리 ≈ (1/레버리지 − 유지증거금률) → 손절보다 먼저 청산되면 **경고 + 신호 제외 옵션**. 예상 손실 = 위험%.
- **하루 손실 제한 2%**(= 0.5% 기준 4R): 도달하면 그날 신규 신호는 기록만 하고 알림 억제(내부 기록 유지). 연속 손실 ≥4회, 최대 낙폭 ≥ 6%(모의 계좌) 경고.
- 상관 위험 표시: 같은 방향 활성 신호 수, BTC 대비 30일 상관 > 0.8인 종목의 동시 신호 → "동일 위험 묶음" 표시, 묶음당 위험 합계 1% 초과 시 경고.
- 제외 규칙: 손절 불명확, 손절 거리 범위 밖, 순 손익비 < 1.5R, 데이터 공백, 레버리지 청산 위험.

## 5. 모의매매 장부 v2 (기존 PAPER 유지, 별도 `state.ab`)
- **신호 ID** = `{전략}-{종목}-{방향}-{트리거봉시각}` 해시 앞 10자 + 전략 ID. 같은 ID는 저장 거부(중복 방지).
- **불변 기록**: 신호 시점의 진입·손절·TP1·TP2·근거·사용 설정(임계값 버전)·가격 스냅샷을 해시로 봉인(`sha256` 체인). 이후 수정 불가, 결과는 별도 레코드로 추가.
- **상태**: 대기(진입 조건 미충족) → 체결(다음 봉 시가 + 슬리피지) / 미체결(유효시간 만료) → TP1·TP2 부분 청산 모델 → 손절 / 만료 / 데이터 공백. 동일 봉에서 손절·익절 동시 가능하면 **손절 우선**.
- **비용**: 수수료 0.05%/편도, 슬리피지 0.05%/편도(기존 15bp 왕복은 민감도), **펀딩비**(OKX 공개 funding-rate-history, 보유 시간 동안 누적).
- **분리**: 과거 검증(`backtest`)과 실시간(`live`)은 저장 위치·필드(`origin`)·집계가 완전히 분리. 같은 표에 섞지 않는다.
- **성적**: 전략별 완료·승률·평균 R·PF·누적 R·최대 낙폭(R·%)·연속 손실·95% 클러스터 부트스트랩 구간(기존 코드). A·B 중복 발생(같은 종목·방향·60분 이내)도 기록.

- 후보 방식: (1) **Artifact 기록 페이지**(링크 한 곳, 신호 ID 선택 → 진입함/패스/늦게 + 숫자 입력, 공유 DB에 저장, 폰에서 입력 쉬움) — 권장 (2) GitHub Issue 양식 (3) CSV를 저장소에 커밋.
