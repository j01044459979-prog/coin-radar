# A/B 전략 알림 디자인 (3.1 표시 계층)

> 전략 판정 로직과 무관한 **표시 계층**이다. 3.1 A/B 전략이 같은 입력(`card`)을 만들어 넘기면 이미지·캡션·대체 발송이 동일하게 동작한다.
> 기존 운영 알림(정기 TOP2 분석, 기회 포착, 현재 진입 후보)은 이 모듈을 쓰지 않으며 바뀌지 않는다(테스트로 고정).

## 문구
| 구분 | 문구 |
|---|---|
| 전략명 | `A전략 · 추세돌파형`, `B전략 · 눌림목 재진입형` |
| 정기 분석 | `📊 TOP2 시장 분석 · 관찰용` |
| 기회 포착 | `🔎 기회 포착 · 진입 전 관찰` |
| A/B 진입 | `📈 A전략 · 모의매매 신호`, `📉 B전략 · 모의매매 신호` |
| 필수 표시 | `모의매매 · 미검증 전략` (이미지 칩·하단, 캡션 3번째 줄) |

`MESSAGE_TYPES`·`typeLabel()`은 상수만 제공한다. 기존 정기 분석·기회 포착 메시지에 유형 머리말을 붙이는 것은 운영 문구가 바뀌므로 **별도 승인 후** 적용한다.

## 이미지 (세로 1080×1560 PNG)
상단 전략명 띠(전략 색) → 종목 + LONG(초록)/SHORT(빨강) 대형 배지 → 칩(모의매매·미검증, 손익비, 손절폭) → 실제 확정 15분봉 + 거래량 + 진입가·손절가·TP1·TP2 가격선 → 진입 근거 2~3개 → 무효화·면책. 글씨는 16px 미만으로 내려가지 않는다. 기존 `signal/chart.mjs`의 렌더러·글꼴을 재사용했고, 전략 카드는 `opts.strategy`가 있을 때만 바뀐다.

## 캡션 (3줄, 이미지 실패 시 같은 텍스트로 대체)
```
📈 A전략 · 추세돌파형 | BTCUSDT LONG
진입 100 · 손절 98 · TP1 103 · TP2 104
모의매매 · 미검증 전략 · 15분봉 돌파·거래량 확인
```

## 입력 `card`와 검증
`strategy('A'|'B')`, `symbol`, `dir`, `entry`, `stop`, `tp1`, `tp2?`, `summary`(한 줄·폭 30 이내), `reasons`(2~3개), `c15`(실제 확정 15분봉), `triggerT`, `triggerCloseT`, `validUntil`.
손절·목표가 방향이 틀리거나 값이 없으면 거부한다. 손익비는 입력 가격에서만 산식으로 계산한다. `승률·확률·매수·매도·확정 수익` 등은 거부한다.

## 전송 (`deliverCard`)
사진 우선. 이미지 생성 실패·15초 초과·사진 HTTP 4xx(429 제외) 거절이면 같은 캡션을 텍스트로 보낸다. 429·5xx·네트워크 오류는 호출자의 장부·재시도 규칙에 맡기려 예외로 던진다.
