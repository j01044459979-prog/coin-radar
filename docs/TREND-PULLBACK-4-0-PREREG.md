# COIN RADAR 4.0 신규 전략 연구 — 사전 등록 (결과를 보기 전에 고정)

> 이 문서는 **어떤 백테스트도 실행하기 전에** 커밋한다. 아래 규칙·임계값은 실행 결과를 보고 바꾸지 않는다.
> 결과가 나빠도 그대로 보고한다. 이 연구는 읽기 전용이며 운영(Telegram, GitHub 스케줄, Cloudflare), main, PR #24·#25와 무관하다. 실거래 주문 기능은 없다.

## 0. 데이터 오염에 대한 정직한 선언
- 개발(2023-11-17~2024-10-17), 검증(2024-10-17~2025-04-17), 이미 본 구간(2025-10-17~)은 3.0 연구에서 이미 사용했고 시장 흐름도 연구자가 알고 있다. **이 구간들은 '미공개 데이터'가 아니다.** 신규 전략의 규칙은 3.0 결과를 보고 만들 수 없도록 아래에 고정하며, 이 구간에서의 통과는 '약한 증거'로만 취급한다.
- 진짜 미공개 구간은 **최종 테스트 구간(2025-04-17~2025-10-17) 하나뿐**이다. 후보 규칙 동결 후, **사용자 승인을 받아 한 번만** 사용한다. 이번 실행에서는 평가하지 않는다(코드가 해시 일치 없이는 실행되지 않음).
- 가격 데이터를 새로 내려받을 수 없는 한 '새 데이터'는 존재하지 않는다. 직전 연도(2022~2023-11) 데이터는 이 환경에서 확보하지 못했으므로 **'검증 불충분' 판정의 근거**로 보고서에 명시한다.

## 1. 전략 정의 (고정 규칙, 파라미터 탐색 없음)
모든 계산은 신호 봉 i가 마감된 시점에서 **마감된 봉만** 사용한다. 체결은 i+1 시가(+슬리피지), 엔진은 3.0 연구와 동일(손절 우선, 갭 처리, 수수료·슬리피지·펀딩, 최대 보유 48봉, 쿨다운 6봉, 종목당 1포지션).

### ① 4시간봉 추세 (마감된 4H 봉만, 1H 데이터를 UTC 4시간 경계로 집계)
- 스윙 피벗: k=3 (좌측 3봉보다 높고(낮고) 우측 3봉 이상(이하) — 3봉이 지나야 확정, 확정 전에는 사용하지 않음).
- **상승 추세(롱 우선)**: EMA50 > EMA200 이고 종가 > EMA200 이고, 확정된 최근 두 스윙 고점이 HH, 최근 두 스윙 저점이 HL.
- **하락 추세(숏 우선)**: EMA50 < EMA200 이고 종가 < EMA200 이고, 최근 두 스윙 고점이 LH, 두 스윙 저점이 LL.
- 그 밖(횡보·혼조)은 관망(신호 없음). 상승 추세에서는 롱만, 하락 추세에서는 숏만.
- BTC 필터(전략 C·D에서만): BTC 4H 추세가 같은 방향. 판정은 EMA 정렬만 사용(EMA50 vs EMA200 및 종가 vs EMA200, 구조 조건 없음).

### ② 1시간봉 진입 (롱 기준, 숏은 대칭)
1. 지지 구간(zone) 후보 — 4H 스윙 저점(최근 60개 4H 봉 이내 확정)과 **돌파로 지지 전환된 4H 스윙 고점**(4H 종가로 돌파, 돌파가 최근 20개 4H 봉 이내). 구간 폭은 레벨 ±0.3×ATR(4H,14). 확정 후 4H 종가가 구간 하단 아래로 내려간 적이 있으면 무효.
2. 눌림: 최근 12개 1H 봉(신호 봉 포함) 중 저가가 구간 상단 이하로 닿았고, 12봉 동안 구간 하단 아래로 1H 종가 마감이 없었으며, 12봉 직전 봉의 종가는 구간 상단 위(위에서 내려온 눌림). 닿은 후보가 여럿이면 상단이 가장 높은(가격에 가까운) 구간.
3. 재진입 확인 캔들(신호 봉): 양봉이고 종가가 직전 봉 종가보다 높으며 종가가 구간 상단 이상(구간 회복).
4. 추격 제한: 신호 봉 종가 − 구간 상단 ≤ 1.0×ATR(4H) 이고 신호 봉 고저 폭 ≤ 2.0×ATR(1H,14).
5. 거래량(전략 B·D에서만): 신호 봉 거래대금 ≥ 직전 20봉 평균의 1.2배 **그리고** 눌림 구간 봉들의 평균 거래대금 ≤ 직전 20봉 평균의 1.0배.
6. 손절: min(눌림 12봉 최저가, 구간 하단) − 0.5×ATR(1H). 신호 봉 종가 기준 손절 거리가 1.0×ATR(1H) 미만(너무 좁음) 또는 3.5×ATR(1H) 초과(너무 넓음)이면 신호 없음.
7. 목표: 신호 봉 종가 + 2.0×(종가−손절) (손익비 1:2 고정). 위쪽 실제 저항(4H 확정 스윙 고점 최근 120개 4H 봉, 최근 72개 1H 봉의 최고가 중 종가+0.1×ATR(1H)보다 높은 것 중 가장 가까운 것)까지의 거리가 목표 거리 이상이어야 한다(저항이 없으면 통과). 목표가 저항 너머면 신호 없음.
- 3.0 전략 B의 규칙(20봉 고점 돌파 → 레벨 재테스트, 상대거래량 2배 조건, 레벨 근접 허용치, 돌파 연령 등)은 **재사용하지 않는다**. 지지 구간은 4H 구조에서 오고, 눌림은 구간 접촉 + 회복 캔들로 정의한다.

### ③ 비교 대상 (이 네 가지가 사전 등록 후보의 전부)
| 코드 | 정의 |
|---|---|
| A | 4H 추세 + 1H 눌림목 (위 ①②의 1~4, 6, 7) |
| B | A + 거래량 확인 (5 추가) |
| C | A + BTC 4H 추세 필터 |
| D | A + 거래량 + BTC 필터 |

비교 기준선(동일 엔진·동일 비용·동일 계정 가정): 3.0 전략 A, B, A+B(PRIORITY), 기존(2.x) 1H 근사 `legacy2`, 무작위 진입(`random`), 4H 추세 방향 무작위 진입(`randomTrend`: 눌림목 타이밍 효과를 분리하는 대조군; 추세 존재 시 봉당 0.4% 확률로 추세 방향 진입, 손절 1.5·목표 3 ATR(1H)).

### ④ 인기 지표의 역할 (진입 조건에 사용하지 않음)
Supertrend(1H, 10/3)·RSI(1H,14)·MACD(1H,12/26/9)·EMA는 **참고 분석 전용**이다. 거래 메타에 기록해 "일치한 거래와 불일치한 거래의 성과가 다른가"만 사후 분석한다. 점수를 승률로 표시하지 않으며, 일치 여부만으로 신호를 만들지 않는다.

## 2. 위험 관리 가정 (연구용)
- 거래당 계좌 위험 0.5% (계정 10,000 USDT 가정; 거래소 최소 주문 수량 미달이면 거래 건너뜀), 동시 포지션 최대 3개(포트폴리오 시뮬레이션: 진입 시각 순서, 동시 진입 시 종목명 순 — **청산 시각으로 정렬하지 않는다**. 3.0 연구의 `portfolio`는 동시 진입 시 청산이 빠른 거래를 우선했으므로 신규 모듈에서 이 미래 정보 의존을 제거한다).
- 레버리지/청산 위험 별도 검증: 포지션 명목가 = 위험금액 ÷ 손절폭이므로 계정 대비 실효 레버리지 = 0.5% ÷ 손절폭(%)이다. 사용자가 고정 레버리지 L(3, 5, 10, 20배)을 쓴다고 가정하고, 격리 마진·유지증거금률 0.5%로 청산 거리 ≈ 1/L − 0.5%를 계산해 ① 손절가가 청산가보다 먼 거래 비율(손절 전에 청산되는 거래) ② 손절 이탈(갭 포함) 최대 불리 이동이 청산 거리를 넘은 거래 수를 보고한다. (거래소별 실제 청산 공식·단계별 증거금은 단순화한 가정)

## 3. 평가 구간과 통과 기준
- 구간: 개발(탐색 허용, 단 규칙 변경 금지), 검증, 이미 본 구간, 최종(이번 실행 제외). 구간별 시점 유동성 유니버스(직전 30일 거래대금 상위 20), 구간 경계 48시간 엠바고, 경계를 가로지르는 거래는 purge.
- Walk-forward: 이 전략은 **학습되는 파라미터가 없다**(규칙 전부 사전 고정). 그래서 재학습형 WF가 아니라, 개발+검증+이미 본 구간을 **달력 분기별 연속 접힘(fold)** 으로 나눠 성과가 시간에 걸쳐 안정적인지 본다. 파라미터를 접힘마다 다시 뽑는 방식은 사용하지 않는다.
- **OOS 풀** = 검증 ∪ 이미 본 구간 (개발은 탐색 구간으로 판정에 쓰지 않는다. 단 앞서 선언했듯 완전한 OOS는 아니다).
- 통과 기준(모두 충족해야 하며 OOS 풀 기준, 비용 반영):
  1. 청산 거래 ≥ 100건  2. 평균 R > 0  3. 평균 R 95% 신뢰구간(주 단위 블록 부트스트랩) 하한 > 0  4. PF ≥ 1.15
  5. 비용 1.5배·2배 스트레스에서도 평균 R > 0
  6. 특정 종목 집중 없음: 수익 상위 3종목 제외 후에도 평균 R > 0
  7. 특정 기간 집중 없음: 수익 최상위 분기 1개 제외 후에도 평균 R > 0, 그리고 검증·이미 본 구간 각각의 평균 R > 0
  8. 특정 국면 집중 없음: n ≥ 20인 국면 중 2곳 이상에서 평균 R > 0
- 포트폴리오 최대 낙폭(위험 0.5%, 동시 3개)을 모든 변형에 대해 보고한다(통과/실패 기준은 아님).
- **모든 기준을 통과해도 실전 추천 금지.** 통과는 '그림자 모드 후보 자격'일 뿐이며, 최종 구간 1회 평가와 사용자의 별도 승인이 먼저다.
- 다중 비교: 사전 등록 후보는 A·B·C·D 네 가지. 신뢰구간은 다중 비교 보정을 하지 않았으므로(보정 시 더 엄격해짐) 경계선 통과는 약한 증거로 해석한다.

## 4. 시험 기록 원칙
- 이 연구에서 평가하는 모든 변형·파라미터 조합을 보고서에 기록한다. 규칙·임계값은 결과를 본 뒤 바꾸지 않는다. 바꾸고 싶으면 **새 사전 등록 문서**를 만들고 해당 가설은 '사후 가설'로 표시한다.
- 알려진 한계(보고서에 그대로 명시): 생존 편향(현재 거래되는 종목만 수집), 2.x 전략의 1H 근사, 신호 수 감소는 개선으로 치지 않음.
