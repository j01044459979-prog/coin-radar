- Scores are heuristic, not probabilities: trend 20, short-term 20, structure 15, volume 10, volatility 15, relative strength 10, funding/OI 10. Funding/OI not implemented yet (explicitly missing, maximum 90/100). No renormalization. Require core data and >=70 in gate-on. Thresholds require walk-forward real-data verification with fees/slippage and alert coverage; compare against unchanged baseline by direction and strategy, including missed signals, drawdown and net returns. Do not activate gate-on solely on unit tests.

Three levels at entry, 0.3R, 0.6R toward original stop, cumulative hypothetical average assumes equal units per level; never assumes user quantities or actual fills. No account equity, margin or size in that plan. Chart captions must retain full plan or fall back to text. Levels are conditional on original structure/stop remaining valid; no orders.
- Workflow defaults to preview / price-only on. Existing legacy sizing tools and actual trade journal are not modified. No Apps Script deployment is needed for these radar-side changes; RICH300 existing code/other flows are separate.
