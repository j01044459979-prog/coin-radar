## 해석 (한계)
1. 모든 코호트의 신뢰구간이 0을 포함한다. **통계적으로 우위가 있다고 말할 수 없다.** 대조군(무작위 진입)과도 구별되지 않는다.
2. 3단계 신호는 274일 동안 106건(종목·일당 0.02건)으로 표본이 작다. 3단계 + 거래량 확대는 18건이라 어떤 결론도 낼 수 없다.
3. 조건 적합도 점수는 결과를 가려내지 못했다(ρ≈0). 거래량 확대 필터는 오히려 평균을 낮췄고(−0.064), 눌림 중 거래 위축 필터만 +0.015였으나 신뢰구간이 0을 크게 포함한다.
4. 3단계의 목표 도달은 24%인데 무효화가 46%, 만료가 30%다. 평균 순손익비가 +0.12R인 것은 소수의 큰 승리에 의존하고 중앙값은 −0.23R이다.
5. 전반/후반 기간 결과가 서로 다른 부호인 코호트가 많다(예: 3단계 + 거래량 확대 +0.26 → −0.18). 안정적이지 않다.
6. 가중치와 임계값은 **임의로 바꾸지 않았다.** 점수를 이 결과에 맞춰 조정하면 과최적화가 된다.

## 데이터 누수·미완성 봉·미래 정보 점검
- 확정 봉만: `parseCandles`가 `confirm=1`만 통과시키고, CLI가 마감 시각이 현재 이후인 봉을 한 번 더 제외한다.
- 시점 i의 판정에는 i번째 봉까지의 1H(최근 150개)와 신호 봉 마감 시각까지 마감된 4H(최근 300개)만 넣는다. 4H는 전체 1H에서 집계하되 마감 시각이 신호 봉 마감 이전인 것만 사용한다.
- 테스트 `백테스트 인과성`: 같은 시리즈 뒤에 데이터를 600봉 더 붙여도 앞선 이벤트(기간 안에 끝난 것)의 단계·점수·결과가 비트 단위로 같다.
- 체결은 신호 다음 봉 시가(마감가 체결을 가정하지 않음). 결과 측정은 신호 이후 봉만 사용한다.
- 알려진 한계: 현재 상위 종목만 사용(생존 편향), 상한 미재현, 비용은 고정 10bp 가정(실제 슬리피지는 변동성에 따라 큼), 동일 시점 종목 간 상관(군집 부트스트랩으로 일부 반영).
