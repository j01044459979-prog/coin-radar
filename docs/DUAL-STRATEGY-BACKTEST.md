## 결론 (먼저)
1. **어떤 전략도 비용 반영 후 통계적으로 유의한 양(+)의 기대값을 보이지 못했다.** 전략 B와 A+B는 기대값이 음수이고 95% 구간이 0 아래다. 전략 A는 0과 구분되지 않는다. 기존(근사) TP2=2R이 가장 낫지만(+0.054R) 기간 외 구간에서는 −0.011R로 사라진다.
2. A+B(−0.099R)는 무작위 진입 기준선(−0.122R)과 구간이 겹쳐 **엣지가 있다고 말할 수 없다.** 전략 B 단독(−0.157R)은 기준선보다 오히려 낮다.
3. 신호가 너무 잦다(A 4,802건 · A+B 1,709건 / 25종목·1년). 75점 조건이 충분히 선별적이지 않아 거래 수는 많고 비용(거래당 0.04~0.08R)만 쌓인다.
4. 따라서 **듀얼 전략을 운영 추천에 쓰는 것은 권하지 않는다.** 코드는 기본 꺼짐(`RADAR_DUAL`/`RADAR_DUAL_REPORT` 미설정)으로 두고, 그림자 모드(계산·기록만)로 앞으로의 실거래 환경 표본을 모으는 용도로만 사용 권장.

## 6) 한계 (과최적화·표본)
- 규칙·임계값은 결과를 보기 전에 고정했고 이 데이터로 조정하지 않았다(그래서 과최적화 위험은 낮지만, 양(+) 결과가 아니므로 의미가 제한적).
- **생존 편향**: 종목을 현재 거래대금 상위로 골랐다(과거에 상위였다가 사라진 종목 없음).
- **기존 전략은 근사**: OI·펀딩 과거 이력이 없어 가격·거래량 성분만 1시간봉으로 재현했다. 운영 중인 5분봉 전략의 성과로 읽으면 안 된다.
- **단일 해상도(1시간봉)·단일 1년**: 상승장 표본이 작고, 다른 국면에서는 결과가 달라질 수 있다.
- **동시 포지션 상관**: 종목별 독립 시뮬레이션이라 실제로 같은 시각에 여러 종목이 같은 방향으로 겹치는 위험(포트폴리오 낙폭)은 최대 낙폭(R)에 일부만 반영.
- 펀딩·수수료는 고정 가정(실제 등급·메이커 주문·펀딩 이력과 다름), 체결은 시가 + 고정 슬리피지로 단순화.
- 95% 구간은 거래를 독립으로 본 부트스트랩이라 시간 상관이 있으면 실제 불확실성은 더 크다.
