`관중 유선 26년도꺼만` 스프레드시트에 연결된 유선 실적관리 웹앱 V1.

- Script ID: `.clasp.json` 참고
- 소스: `src/` (Code.js, index.html, appsscript.json)

## 데이터 구조
- `유선_개통보고` : 웹앱 유선판매보고 원본 (모든 월 누적, `적용월` yyyy-MM 으로 구분)
  - 직원 보고 원문을 붙여넣기 → [내용 확인]에서 파싱 결과 확인 → 저장 (21번째 열 `원문보고`에 원문 전체 보관)
  - 원문의 '처리방식' 2회: GTT 이전 = 사은품처리방식, GTT 이후 = GTT처리방식
- `유선_설정` : 동판유형별 실적 분류 (순신규실적 / 순신규동판 / 신동 / 약갱동판)
  - 값: `미분류`(집계 제외) · `0` · `1`(건당) · `회선수`(동판회선수만큼)
  - A열에 동판유형을 추가하면 개통보고 선택 목록에 바로 반영
- `유선_목록` : 작업자 / 사은품권종 선택 목록
- 기존 월별 장표(`26년 1월` 등)는 **읽기 전용**으로 개통리스트에만 합쳐서 표시 (이관/수정 없음)
  - 열 위치는 실제 헤더 글자(고객명/접속번호/지급사은품/사은품 발송·수령번호)로 찾고, 항목마다 1개 열만 확인될 때 연결
  - 결과는 `유선_기존장표매핑` 시트에 기록 (상태: 자동/감지실패/확정). 관리자가 열을 지정하고 `확정`으로 바꾸면 그 값 사용
  - 같은 적용월+같은 접속번호(숫자 비교)는 웹앱 데이터 우선 1건만 표시
- 실적사항 = 기존 장표 실적 열 직접 합산 + 유선_개통보고(유선_설정 분류) 합산, 같은 월+접속번호는 웹앱 우선
  - 기존 장표 실적 열은 헤더명 정확 일치로 감지: 판매자(판매자/직원명/담당자), 순신규, 신동, 동판순신규(순신규동판), 동판약갱(약갱동판)
  - 결과는 `유선_기존장표실적매핑` 시트에 기록, `확정` 행은 헤더 탐색 없이 지정 열 사용
  - 셀 숫자 그대로 합산(빈칸/'-' = 0), 못 찾으면 그 월은 오류 표시하고 웹앱 보고만 집계

실적은 저장 시 누적하지 않고, 조회할 때마다 `유선_개통보고` + `유선_설정`으로 다시 계산한다. (2026-01~08)

### 2026-09 이후: 관리자 수기 입력
- `유선_실적수기입력` : 개통건별 실적 수기 입력 (처음 [실적 저장] 시에만 생성, 조회 시 생성 안 함)
  - 헤더: 등록ID · 적용월 · 접속번호 · 고객명 · 작업자 · 순신규 · 순동 · 약동 · 신동 · 수정일시
  - 식별키 = 적용월 + 접속번호(숫자 비교). 같은 키는 한 행만, 다시 저장하면 덮어쓰기(누적 아님)
  - 작업자 = 웹앱 보고의 작업자 / 기존 장표의 판매자(판매자·직원명·담당자 헤더)
- 실적사항 = 이 시트의 선택 월 행을 작업자별 합산 (순신규 / 순동 / 약동 / 신동)
- 9월 이후에는 MIT 약동 자동분류, 구분·I/T/GTT 분석, `유선_설정` 분류를 실적에 쓰지 않음 (코드는 보존)
- 개통리스트 카드: 고객명 / 접속번호 / 고객혜택 / 고객혜택 발송번호, 기본 접힘, 한 번에 하나만 펼침
  - 배지: 수기 행이 있으면(0이어도) `실적 입력완료`, 없으면 `실적 미입력`
